Does RightFit understand shoppers better than search did?

In v0.1, CarMax's search returned fitting cars in its top 5 results 95% of the time when the query read like filters, and 37% of the time when it read like a person. This page runs the same 20 queries through RightFit, live, and scores them the same way.

  • Fit = a car in the top 5 meets every hard constraint the shopper stated. Each query's test is written in code, independently of the model.
  • Inventories differ: CarMax had tens of thousands of cars, RightFit has 567 synthetic ones. When fewer than 5 cars in stock fit, the bar is however many do. When none do, the query is scored on whether RightFit says so.
  • Since v0.3.1 it also flags what a top-5 score hides: filters nobody asked for, questions nobody needed, and matching cars the agent missed.
  • The 20 v0.1 searches have now been used to tune the agent, so they're a practice set. The held-out buyers set is 6 searches in real buyers' own words, with answer keys from what each buyer said they'd consider. It was never used for tuning.
